Active provider

Choose which provider Lumen routes generations to. Devin built-in and Hugging Face work directly from the browser; the others require a proxy URL.

Devin built-in No key needed

A tiny in-browser "model" that picks a curated CC0 sample clip based on your prompt's keywords (cyberpunk, fantasy, anime, action, …). Useful for design review, demos, and offline playback. No network calls beyond the sample-clip CDN.

Hugging Face token Free tier

Real text-to-video using damo-vilab/text-to-video-ms-1.7b. Generation takes 20–60s on cold start. Get a free read token at huggingface.co/settings/tokens.

Replicate API token

Used for models like stability-ai/stable-video-diffusion. Get yours at replicate.com.

Stability AI key

For stable-video generations. Get a key at platform.stability.ai.

RunwayML key

For Gen-3 Alpha and Gen-2 video models. Get a key at runwayml.com.

Pika key

Pika Labs API key for cinematic generations.

Luma Dream Machine key

For Luma's high-quality 5-second generations.

Proxy URL Recommended

Most providers don't allow direct browser calls. Deploy a tiny relay (any server framework) and paste its URL here. Example endpoints: POST /text-to-video, POST /image-to-video, POST /video-to-video.

Reset

Clear all saved keys and history from this browser. Cannot be undone.
